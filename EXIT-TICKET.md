## Exit Ticket
Answer each question individually

1. In one sentence, define inheritance.

   its a mechanism in a program that allows a new class to get and reuse the fields and methods of pre-existing class

2. What is the purpose of extends?
  The keyword extends is to create the relationship indicating that a new subclass is inheriting from a specific parent of a superclass.

4. What is the difference between a superclass and a subclass?
     A superclass is the existing class and the subclass is the new class that was inherited from the superclass. 

5. Give one advantage of inheritance.
   One advantage is code reusability. It allows you to reuse code from an existing class without having to rewrite it.
